# Float

Float holds references to files and folders in a compact floating shelf. Adding an item does not copy or move its original. Removing a reference, clearing the shelf or closing its window does not delete a file.

Hover or click to expand the stack. Drag file artwork to carry files into another app; use the header or paperclip to reposition the shelf. Drop more files to add them, select multiple rows, or attach the shelf to a screen edge. Large collections scroll within the display's usable area.

| Action | Shortcut |
| --- | --- |
| Select all | ⌘A |
| Copy files | ⌘C |
| Copy paths | ⌘⌥C |
| Add clipboard files | ⌘V |
| Preview | Space |
| Open | Return / ⌘O / double click |
| Reveal | ⌘R |
| Remove selected references | Delete |
| Clear selection, then collapse | Escape, Escape |

The explicit `--float-smoke OUTPUT` entry point exercises generated fixtures, selection, keyboard controls, edge placement and preservation of source bytes. It is separate from the normal application.
