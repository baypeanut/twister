Twister can now update itself from inside the app.

- New releases appear in the workspace and menu bar without interrupting your work.
- Check for updates automatically or from Settings. Choose when to download and install.
- Active conversions and tool setup finish before an update restarts Twister.
- Update feeds and downloads are verified before installation.

This is the first release with automatic update checks enabled. Install it once manually if your current copy was built from source with updates disabled.
