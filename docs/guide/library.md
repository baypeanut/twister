## Find recent results

Library keeps the most recent 50 successful job records. Open it with ⌘2 to return to exported results without finding their folders manually. These entries refer to files on disk; they are not independent backup copies of those files.

## Search and preview

Press ⌘F in Library to search operation titles and output filenames. Use the arrow keys to select a result and Space to preview it. Search follows the selected interface language while leaving filenames unchanged.
