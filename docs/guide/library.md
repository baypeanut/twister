# Library and Float

[Back to Twister](../../README.md)

## Find recent results

Library keeps the most recent 50 successful job records. A batch in which some files failed is recorded with the files that succeeded. Open it with ⌘2 to return to exported results without finding their folders manually. These entries refer to files on disk; they are not independent backup copies of those files.

## Search and preview

Press ⌘F in Library to search operation titles and output filenames. Use the arrow keys to select a result and Space to preview it. Search follows the selected interface language while leaving filenames unchanged.

## Use a result again

Press Return or use the reuse button to bring available output files back into Twister. Missing files cannot be reused, and reuse is unavailable while a task is running. If every file in a record is gone, Twister leaves the current selection intact and reports the missing result.

## Carry files with Float

Float is an explicitly opened shelf for carrying files between apps. In the shelf, Space opens Quick Look, Return opens the selection, ⌘R reveals it in Finder, ⌘C copies files and ⌥⌘C copies paths. Delete removes the selected shelf references rather than deleting those files from disk.

## Control Finder reveal

Automatic Finder reveal is off for a fresh profile. Enable **Reveal finished files in Finder while Twister is active** in Settings if you want it. An export that finishes while another app is active keeps its result available in Twister without switching focus to Finder.
