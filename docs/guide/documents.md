# Working with documents

[Back to Twister](../../README.md)

## Choose a supported route

Document routes include text, Markdown, HTML, rich text, DOCX and Pages, with separate conversion choices for spreadsheets, presentations and EPUB books. Choose a source file to see its available targets. Converting to an image renders pages, while converting to text discards page layout.

## Convert Pages files locally

Twister parses supported modern Pages documents locally and builds Pages output through its bundled conversion resources. Apple Pages does not need to be launched for those routes. Complex documents can still differ after conversion, so inspect tables, images and paragraph flow in the exported copy.

## Prepare Office conversions

Routes that use the Office converter require LibreOffice. Twister can detect a usable installation or install the optional Office tool group. Each conversion uses an isolated working profile, allowing conversion work to stay separate from documents open in your regular LibreOffice session.

## Choose a PDF export layout

For PDF-to-DOCX or PDF-to-Pages conversion, Settings offers **Editable paragraphs and tables** and **Preserve original pages**. Choose the first when editing reconstructed content matters most, or the second when retaining the page appearance matters most. Review the output because a PDF does not necessarily contain the original document structure.

## Choose an EPUB layout

EPUB output can use reflowable text or preserve original pages. Reflowable content adapts to the reader layout; fixed pages keep a page-based presentation. Pick the layout before export and check the book in your intended reader, including images and page navigation.
