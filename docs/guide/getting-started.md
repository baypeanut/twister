# Getting started

[Back to Twister](../../README.md)

## Choose a selection

Open Twister from its menu-bar icon, then choose files with **Choose files** or ⌘O. You can also drop files into the workspace. Start with one file while learning a tool; the available actions depend on both its format and the number of selected files.

## Paste from the clipboard

Press ⌘V in the workspace to import supported files, an image, text or a media link. Twister checks clipboard images before decoding them and can reject oversized content. If an image cannot be pasted, save it as a file and choose it from the workspace to see the relevant file error.

## Use Finder gestures

While dragging files in Finder, hold Shift for conversions, Command for tools or Control for file actions. The modifier choices can be changed in Settings. These optional gestures use macOS permissions; choosing and dropping files in the workspace remains available separately.

## Understand exports

Conversions and editing tools write separate results. Twister stages an export before publishing it and chooses a new name when the destination already contains that name. Explicit file actions such as **Move** act on the selected files themselves, so distinguish those actions from exporting an edited copy.

## Choose where results go

The default destination is **Beside originals**. Use the output-folder chooser in the workspace or editor footer to save results elsewhere; Twister remembers that folder. A running export keeps the destination it captured when it started, even if you change the preference afterward.

## Reconnect a saved folder

A saved folder may become unavailable after it is moved, removed or loses its access grant. Choose the folder again when Twister asks for renewed access, or restore **Beside originals**. An invalid saved destination stops the export instead of silently sending results to another folder.
